# Данные варианта 1

**Источник:** синтетическая транспортная сеть, сгенерирована скриптом
`../generate_data.py`.

**Seed:** `10131 = 10000 + 100·Q + N`, где `Q = 1` (группа 517), `N = 31`.

**Файлы:**

- `warehouses.csv` — 4 склада и их запасы;
- `stores.csv` — 6 магазинов и их спрос;
- `routes.csv` — стоимости и пропускные способности 24 маршрутов;
- `params.json` — единицы измерения, суммарные запас/спрос, seed.

**Процедура генерации.** Запасы `[130, 110, 100, 90]` ед., спрос
`[60, 70, 50, 80, 60, 70]` ед. Базовые стоимости заданы матрицей 4×6,
к каждой добавлен мультипликативный шум `N(1, 0.08)`; стоимости округлены
до 0.01. Пропускные способности — случайные целые `45…85` ед.; для маршрута
W3 → S6 установлено договорное ограничение 60 ед.

**Единицы:** поток — ед. груза; стоимость — у.е./ед.; пропускная
способность и запасы/спрос — ед.

**Перегенерация:**

```bash
python generate_data.py
```
